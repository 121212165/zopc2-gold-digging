# ZOPC21Launch 掘金实战 · 第 2 期 — 阶段 1 产出

> 21 天出海 AI 社媒工具实战项目 · 阶段 1(08.10 - 08.12):找对方向,拆对产品

## 项目简介

用 AI 做一个海外社媒工具,从 0 到 1 跑通并尝试变现。阶段 1 的全部工作是**数据分析**——用数据验证「哪个方向值得做」:工具链就绪 → 榜单初筛 → 需求验证(关键词 + 用户声音 + 风险核查)→ 找标杆拆解。
