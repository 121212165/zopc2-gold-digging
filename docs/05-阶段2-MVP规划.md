## 二、阶段2 目标

> **一句话**：2 周内，用最小成本把「AI 电商广告素材生成器」MVP 上线，拿到 100 个真实用户试用，验证愿意付费的转化率。

- **时间**：约 2 周（紧跟项目节奏）
- **范围**：只做抄改清单里**最痛的一环**，不做大而全
- **成功指标**：上线后 100 个注册试用 + 至少 10% 愿意进入付费流程（或按项目方标准调整）

## 三、MVP 范围定义

### 3.1 做（MVP 只做这些）

| 功能 | 说明 | 来源 |
|------|------|------|
| 1. 商品图/素材上传 | 用户传产品图或粘贴商品链接 | 工作流第一环 |
| 2. AI 生成广告素材（多尺寸） | 生成 FB/IG/TikTok 多尺寸创意图 + 文案 | 核心价值 |
| 3. 一键导出/下载 | 免费版带水印或限尺寸，付费解锁高清/无水印 | 商业化钩子 |
| 4. 3 次免费额度 | 注册即送 3 次，用完引导付费 | 抄 Promer 的钩子 |

### 3.2 不做（MVP 明确不做）

- ❌ 多语言素材（先做英文，验证模式）
- ❌ 批量处理（上线后按需加）
- ❌ 团队协作/工作流管理
- ❌ 自建模型（直接用现成 API，如图像生成 + 文案模型）

> 原则：**能抄的抄，能买的别造。** MVP 阶段每省一小时开发，都算赢。

---

## 四、技术栈建议

### 4.1 推荐方案（快速上线优先）

| 层 | 选择 | 理由 |
|----|------|------|
| 前端 | Next.js + Tailwind（或 Vercel 一键模板） | 快、SEO 友好、部署简单 |
| 后端 | Next.js API Routes / Supabase | 无服务器成本低 |
| 图像生成 | 现成图像 API（按量付费） | 不造模型，Fast 上线 |
| 文案生成 | 现成 LLM API | 同上 |
| 支付 | Stripe（TrustMRR 可接，A 级收入证据） | 收入可见性最好 |
| 部署 | Vercel | 绑定域名即上线 |

### 4.2 备选（零代码快速验证）

- 用 AI 建站工具/表单工具先做**落地页 + 预约排队**，验证点击量再开发
- 或先用现成模板站（如 MotionSites 类 AI 落地页）挂付费入口

> 目的：**先验证"有人点、有人想买"，再写代码。** 如果落地页 3 天没流量，MVP 就该调整方向而不是继续开发。
