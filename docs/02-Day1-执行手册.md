## 一、项目背景与阶段总览

### 1.1 这是什么项目

ZOPC21Launch 掘金实战（第2期）是一个 21 天的实战项目：
- **目标**：用 AI 做一个海外社媒工具，从 0 到 1 跑通并尝试变现
- **形式**：6 场实战直播 + 每日落地指南 + 实时答疑
- **阶段划分**：找方向 → 做产品 → 上线 → 增长 → 商业化

### 2.4 证据分级体系（判断收入数字可信度）

| 等级 | 来源 | 可信度 |
|------|------|--------|
| **A** | 支付 API 验证（TrustMRR 接 Stripe 实盘） | 🟢 最高，可当结论 |
| **B** | 平台披露（收购挂牌、AppSumo 销量） | 🟢 高，可当结论 |
| **C** | 创始人自述（Indie Hackers、推特） | 🟡 中等，只能当线索 |

## 四、Day 1 详细执行步骤

### Step 1：安装/注册工具链（约 20 分钟）

#### ① AITDK 插件（Chrome 扩展）
1. 打开 Chrome 浏览器 → 访问 Chrome 应用商店
2. 搜索 **AITDK**（AI Toolkit 类插件）
3. 点击「添加到 Chrome」
4. 安装完成后，工具栏会出现 AITDK 图标
5. **用途**：浏览 AI 工具网站时，直接显示该网站的流量数据、用户活跃度、技术栈等信息

#### ② Semrush 账号（免费版）
1. 访问 semrush.com → 点击 Sign Up
2. 用 Google 账号一键注册（需要能访问海外网络）
3. 免费版每天有少量查询额度（够 Day 2 用）
4. **用途**：关键词研究（Volume/KD/CPC/意图）——Day 2 的核心工具

#### ③ SimilarWeb 账号（免费版）
1. 访问 similarweb.com → 注册免费账号
2. 免费版每天约 10 次查询额度
3. **用途**：查看竞品网站的流量来源、流量规模、受众画像

#### ④ TrustMRR（顺手注册备用）
1. 访问 trustmrr.com 或对应入口
2. 注册账号（免费额度）
3. **用途**：验证 AI 产品真实收入（Day 3 拆解标杆时用）

#### ⑤ 工具链检查清单 ✅
- [ ] AITDK 已安装并显示在 Chrome 工具栏
- [ ] Semrush 账号已注册（能登录）
- [ ] SimilarWeb 账号已注册（能登录）
- [ ] （可选）TrustMRR 账号已注册

### Step 2：Toolify 榜单研究（约 30-40 分钟）

#### ① 打开 Toolify
- 访问 **toolify.ai**（AI 产品数据平台）

#### ② 按增长率排序浏览
1. 进入首页 → 找到工具排行榜
2. 点击排序方式 → 选择 **按增长率排序**（Growth Rate）
3. 浏览 Top 50 左右的产品
4. **记录**：哪些类别/方向的产品增长率最高？

#### ③ 切换子榜单
1. 找到榜单分类筛选（Category/Tag）
2. 依次查看以下子榜单（每个花 3-5 分钟）：
   - **Social Media Tools**（社媒工具）
   - **Marketing Tools**（营销工具）
   - **Content Creation**（内容创作）
   - **SEO Tools**（SEO 工具）
   - **Writing Tools**（写作工具）
3. 每个子榜单记录：Top 3 产品的名称 + 增长率

| 子榜单 | Top 产品 | 增长率 | 月访问量 | 你的兴趣度 (1-5) |

> 💡 **分析提示**：增长率高 = 需求在爆发；访问量高 = 已经验证的市场。两者结合看：高增长 + 低竞争 = 最佳机会。

## 七、常见问题

**Q：Toolify 打不开/加载慢怎么办？**
A：Toolify 需要海外网络。确保你的网络环境能访问 Google（项目工具清单里已强调）。

**Q：榜单数据看不懂怎么办？**
A：不需要看懂所有指标。Day 1 只看两个数字：**增长率**（方向是否在涨）和**月访问量**（市场大小）。其他指标后面几天再用。

**Q：选不出方向怎么办？**
A：用排除法。从"你平时最关注/最想解决什么问题"出发，再在 Toolify 榜单里找对应分类。不要选完全陌生的领域——21 天不够你从零学一个新行业。

**Q：候选方向必须 3 个吗？**
A：至少 2 个，最多 3 个。太多说明筛选不够狠，太少说明你还没看够榜单。
