# 问题记录:CDP 浏览器接管失败 → 登录态恢复与替代方案

> 记录时间:2026-08-15
> 场景:需要接管浏览器访问 ZOPC 会员站(ZOPC Builder / ai798lab.com)找 sdd-suite
> 状态:已记录解决方案,待用户侧提供 sdd-suite 信息

---

## 一、问题现象

1. 通过 `browser_attach` 接管调试浏览器失败:`CDP discovery HTTP error`(http://127.0.0.1:9222/json/version 无响应)
2. 之前用 PowerShell 启动的调试 Edge(`--remote-debugging-port=9222 --user-data-dir=C:\Users\lenovo\.evox\edge-cowork`)已不在运行,或端口已断
3. 用户在自己打开的**普通 Edge**(非调试实例)里登录了 ZOPC 会员站,但我**无法直接接管用户已打开的浏览器窗口**:
   - `browser_attach` 只能连 `--remote-debugging-port` 的调试实例
   - 用户浏览器未开调试端口,无法被 CDP 驱动
4. `cu_screenshot` 能看到屏幕,但 `cu_get_app_state` / `cu_focus_app` 对 Edge 返回「0 窗口」/「no visible window」——Edge 在独立界面(可能无可见 AX 窗口或运行在另一虚拟桌面)

## 二、排查过程

| 步骤 | 命令/操作 | 结果 |
|------|----------|------|
| 1 | `curl http://127.0.0.1:9222/json/version` | 无响应 → 调试实例已退出 |
| 2 | `netstat -ano \| grep 9222` | 仅残留 FIN_WAIT/CLOSE_WAIT,无活跃监听 |
| 3 | PowerShell `Start-Process msedge --remote-debugging-port=9222 --user-data-dir=...edge-cowork` | 重启成功,但用户看不到这个新窗口(与用户打开的窗口不是同一个) |
| 4 | `browser_attach` 重连 | 若调试 Edge 存活则可连上且**登录态保留**(同一 user-data-dir) |
| 5 | `cu_get_app_state Microsoft Edge` | 0 窗口,无法读用户浏览器 AX 树 |

## 三、解决方案(下次直接照做)

### 方案 A:恢复并保留登录态(首选)
```powershell
# 1. 确认端口
curl http://127.0.0.1:9222/json/version

# 2. 若断了,用【同一个】user-data-dir 重启(登录态 cookie 在里面)
Start-Process 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' `
  -ArgumentList '--remote-debugging-port=9222','--user-data-dir=C:\Users\lenovo\.evox\edge-cowork','--no-first-run','about:blank'

# 3. sleep 5-8 秒后再 attach
browser_attach
```
- **关键**:`--user-data-dir` 必须与首次登录时一致,会员登录态才能保留
- 若用户已在自己浏览器登录,可让用户把登录态迁到调试实例:在调试窗口里再登一次(或复制 cookie)

### 方案 B:接管用户已打开的浏览器(需用户配合)
- 用户普通浏览器**不开调试端口就无法被 CDP 驱动**——这是设计限制,不是 bug
- 让用户在**调试实例窗口**里登录(方案 A 的窗口),或:
- 用户把页面 URL / 关键内容直接贴给 agent,agent 无需浏览器也能处理

### 方案 C:屏幕驱动(兜底)
- `cu_screenshot` 可见用户屏幕,但 Edge AX 树读不到(0 窗口)
- 仅当目标窗口有可见 AX 元素时才用 cu_click_element / cu_mouse_click 坐标操作
- **本次不适用**:用户浏览器不可见/不可驱动

## 四、教训与经验

1. **调试端口断开的根因**:之前启动的调试 Edge 被关闭(可能用户手动关了窗口,或系统清理)。调试实例的窗口如果全被关闭,进程会退出,端口随之失效。
2. **登录态在 user-data-dir,不在浏览器**:只要 user-data-dir 不变,重启后登录态还在——重启调试浏览器不是重新登录的充分条件,但用同一目录即可恢复。
3. **用户已开的浏览器 ≠ 可驱动**:对用户说「我看不到你打开的网页」是真实的——我只能看 CDP 调试实例或屏幕截图,无法注入用户浏览器。
4. **协作分工**:浏览器自动化受阻时,及时切换为「用户侧提供信息(URL/内容/截图),agent 侧处理逻辑」的模式,不硬撑。
